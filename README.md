# PIPE · Shiftee staff guide

한국어·영어·중국어(간체)·스페인어·우즈베크어·몽골어 직원용 인터랙티브 온보딩 가이드입니다. 첫 화면에서 모바일 앱에서 Google 계정(Gmail) 연동 가입을 안내하고, 회사 합류·출근·퇴근·기록 정정을 안내합니다. 상단에 사용자가 지정한 CK Park의 KakaoTalk 문의 정보가 표시됩니다.

**교육용 프로토타입입니다. 실제 출퇴근이나 요청을 전송하지 않습니다.** PIPE의 인증·휴게·승인자·운영 시각과 기능 허용 여부는 아직 확인 전입니다.

## 로컬 확인

저장소 폴더에서 사용 중인 포트를 먼저 확인하고 빈 loopback 포트로 실행하세요. 기존 다른 프로젝트의 서버를 종료하지 마세요.

```sh
lsof -nP -iTCP:8795 -sTCP:LISTEN
python3 -m http.server 8795 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8795/`를 여세요. 런타임 패키지 설치·빌드·계정·DB·API 키가 필요하지 않습니다.

## 정적 호스팅

루트 `index.html`, `styles.css`, `locales.js`, `guide.js`, `assets/`와 `sources.md`를 같은 상대 구조로 제공하면 됩니다. 절대 사이트 경로를 사용하지 않으므로 저장소 하위 경로에서도 동작하도록 구성했습니다. JavaScript와 이미지 파일의 정적 제공이 필요합니다.

GitHub Pages는 `main / (root)`를 게시 원본으로 사용하며, 공개 주소는 [PIPE Shiftee 가이드](https://ckyw.github.io/pipe_shifty/)입니다. `main`에 반영하면 Pages 빌드가 실행됩니다. 게시 후 해당 주소의 콘텐츠를 확인합니다.
- [GitHub Pages 생성 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
- [게시 원본 설정 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 포함 파일

- `index.html`, `styles.css`, `guide.js`, `locales.js`: 모바일 화면, 6개 언어의 전체 안내문·접근성 문구와 탐색 상태. 번역은 로컬 파일이며 외부 번역 서비스에 접속하지 않습니다.
- `assets/clock-ko.png`, `clock-en.png`, `signup-ko.png`, `join-ko.png`: 현재 가이드에서 사용하는 시프티 공식 앱 화면 원본. 과거 QR 원본 파일은 출처 기록 보존용이며 현재 화면에서 참조하거나 로드하지 않습니다.
- `assets/pipe-logo.webp`: 사용자가 제공한 PIPE 로고 원본. 비율·디자인·원본 바이트를 변경하지 않았습니다.
- `sources.md`: 공식 도움말 12개·원본 이미지 URL·조회일·사용 범위.
- `checks/verify.cjs`: 이미 설치된 Playwright와 Chrome을 사용하는 브라우저 검증.
- `verification.md`: 실제 검증 결과와 확인하지 못한 항목.
- `.gitignore`: 로컬 테스트 결과·의존성·자격증명 제외.
- `.nojekyll`: 추후 Pages에서 원본 정적 파일 구조를 그대로 제공하기 위한 표시이며 Pages를 활성화하지 않습니다.

내부 운영 프로젝트의 코드·계정 설정·직원 정보·작업 명세·브라우저 캡처/로그는 포함하지 않습니다.

## 검증

이미 사용 가능한 Playwright 모듈 경로와 위 미리보기 주소를 지정합니다. 테스트 실행을 위해 새 패키지를 자동 설치하지 않습니다.

```sh
SHIFTEE_PLAYWRIGHT_PATH=/path/to/existing/playwright SHIFTEE_PREVIEW_URL=http://127.0.0.1:8795/ node checks/verify.cjs
```

최신 가입 안내 수정본은 **50개 그룹 PASS, 기본 select 키보드 조작 1개 확인 불가**입니다. 콘텐츠 220개 항목의 6개 언어 완결성, Google 전용 가입과 QR 미표시 검증도 통과했습니다. 프로젝트 하위 경로 검증은 이전 검증 기록이며 이번에는 재실행하지 않았습니다. 검증 결과와 캡처는 Git에서 제외된 `output/playwright/`에 생성됩니다. 실제 기기·스크린리더 검증과 기본 select의 사용자 키보드 동작은 별도 확인이 필요합니다. [검증 기록](verification.md)을 참고하세요.

## 이미지 출처와 권리

앱 화면은 [시프티 한국어 공식 도움말](https://shiftee.io/ko/help/article/clockInOut)과 [영어 공식 도움말](https://shiftee.io/en/help/article/clockInOut)의 예시이며 2026-10-16에 조회했습니다. [원본 URL·화면 대응 기록](sources.md)을 유지합니다.

공개 도움말이라는 이유만으로 이미지 재배포 허용을 단정하지 않습니다. 시프티 이미지의 재배포 권리는 아직 확인되지 않았습니다. 가이드는 검토용 프로토타입이며, 직원 공유·사이트 공개 전에 이용 권리를 확인해야 합니다. 이 저장소에 모든 제3자 이미지의 재사용을 허용하는 포괄적 라이선스를 부여하지 않습니다.

PIPE는 QR을 사용하지 않습니다. 현재 가이드에는 QR 메뉴·스캔/카메라 도움말·QR 인증 문구가 없으며 QR 이미지를 로드하지 않습니다. 과거 `#qr/0`을 포함한 QR 링크는 회원가입 첫 화면 `#signup/0`으로 이동합니다.

## 회원가입 및 다국어 안내 변경

2026-10-19: `signup`을 첫 안내로 추가했습니다. 초기 버전은 Google 계정 연동 가입을 권장했습니다. 현재 버전은 Google 연동 가입만 안내하며 PC·이메일 가입 절차를 제공하지 않습니다. 가입과 회사 합류는 별도 단계입니다. 기존 출퇴근 해시 링크는 유지됩니다.

가이드의 6개 언어는 실제 시프티 앱의 지원 언어를 뜻하지 않습니다. 중국어·스페인어·우즈베크어·몽골어 가이드에서는 영어 공식 스크린샷을 사용하며, 장소 선택 단계는 기존과 같이 한국어 원본을 사용합니다. 원본 언어를 번역된 안내문에 표시합니다.

작업 브랜치: `codex/onboarding-signup-five-languages`. 사용자가 커밋·push·공개 사이트 반영을 승인했습니다. 공개 게시 원본은 `main`이며, 검증 결과는 `verification.md`의 최신 항목을 확인하세요.

## QR 안내 제거

2026-10-22: 사용자 확인에 따라 PIPE는 QR을 사용하지 않습니다. QR 전용 흐름과 도움말을 삭제하고 6개 언어의 일반 출근 메모 및 운영 확인 목록에서도 QR 언급을 제거했습니다. 현재 흐름은 회원가입·출근·퇴근·기록 정정 네 가지이며 도움말은 9개입니다. 기존 QR 해시 링크는 회원가입 첫 단계로 이동합니다.

작업 브랜치: `codex/remove-qr-onboarding`. 이 후속 변경은 로컬 커밋으로 보관합니다. 사용자가 다음 요청 작업 후 푸시하기로 했으므로 push·공개 반영은 보류합니다.

## 언어 드롭다운과 모바일 표시

2026-10-22: 상단 언어 선택을 여섯 개 버튼에서 기본 드롭다운으로 변경했습니다. 각 언어는 원어 표기(한국어, English, 中文, Español, O‘zbekcha, Монгол)로 표시하며, 선택 메뉴의 라벨은 현재 가이드 언어로 바뀝니다. 언어 변경 시 진행 단계·정정 유형·도움말 선택을 유지합니다.

선택 글자는 모든 화면에서 16px, 선택창 높이는 최소 48px입니다. 모바일에서는 로고 옆에 선택창을 배치하고 문의 정보는 다음 줄에 표시합니다. 글자를 줄여 맞추지 않고 선택창 폭과 줄바꿈으로 대응합니다. 이 변경은 아직 커밋·push하지 않았으며 다음 요청까지 로컬에서 검토할 수 있습니다.

## Google 전용 모바일 회원가입 이미지

2026-10-22: 회원가입 4단계를 앱 시작 → Google 선택 → Google 로그인 확인 → PIPE 합류로 정리했습니다. PC 가입과 이메일 가입용 본인 인증·비밀번호·스팸함 안내는 6개 언어에서 제거했습니다.

공식 `signup-ko.png`의 시작 화면과 Google 버튼 영역, 직원 시작 가이드의 `join-ko.png`를 사용합니다. 원본 파일은 수정하지 않고 CSS 표시 영역으로 구분하며, Google 버튼 부분만 확대하여 다른 가입 옵션은 보여주지 않습니다. 모든 언어에서 한국어 공식 원본임을 설명합니다. 로그인 확인 단계의 이미지는 Google 버튼 예시이며 성공 화면을 뜻하지 않습니다.

직원 시작 가이드 이미지는 이전 6자리 코드 화면입니다. 현재 12자리 또는 이전 6자리 코드 입력 경로는 최신 직장 합류 도움말에 맞춰 설명하고, 이미지 속 코드를 실제 코드로 사용하지 않도록 안내합니다.

## 가입 안내 문구 정리

2026-10-22: `#signup/1`과 `#signup/2`의 공식 앱 예시 라벨과 Google 버튼 확대 안내를 숨겼습니다. 다른 단계의 이미지 설명과 원본 링크·대체텍스트는 유지합니다. `#signup/1`은 `(name).pipecompany@gmail.com` Google 계정을 사용하도록 6개 언어에서 안내합니다. `(name)`은 사용자가 지정한 자리표시자입니다.
